## SECCIÓN 3 — Reglas de Implementación SEO

### Jerarquía de Headings (H1-H6)
**REGLA UNIVERSAL:**
```html
<!-- UNA H1 POR PÁGINA -->
<h1>Keyword principal + marca/propuesta</h1>

<!-- H2 para SECCIONES PRINCIPALES -->
<h2>Servicios/Beneficios con keywords secundarias</h2>

<!-- H3 para SUBSECCIONES -->
<h3>Detalles específicos de cada H2</h3>

<!-- H4-H6 solo si es necesario para estructura -->
<h4>Puntos muy específicos</h4>
```

**EJEMPLO PRÁCTICO HOME:**

### Optimización de Imágenes
**NOMENCLATURA DE ARCHIVOS:**
```
❌ MAL: IMG_1234.jpg, foto.png, banner.gif
✅ BIEN: agente-whatsapp-24-7.webp, automatizacion-ia-negocios.jpg
```

**ALT TEXT ESTRUCTURA:**
```html
<!-- FÓRMULA: Qué es + keyword + contexto -->
<img src="bot-whatsapp-restaurante.webp" 
     alt="Bot WhatsApp para restaurante automatizando pedidos de clientes">
```

**FORMATOS RECOMENDADOS:**

- **SVG:** Iconos, logos, ilustraciones simples
- **JPG:** Solo si WebP no es compatible (fallback)
- **PNG:** Solo para capturas de pantalla con texto

**HACIA HOME DESDE:**
- `/auditoria-gratis` → botón "Conocer más servicios"
- Blog → "Descubre todos nuestros servicios"
- Páginas de servicios → "Ver otros servicios"

**ANCHOR TEXT OPTIMIZADO:**


### Core Web Vitals (Velocidad)
**LOS 3 FACTORES MÁS CRÍTICOS:**

1. **LCP (Largest Contentful Paint) < 2.5s**
   - Optimizar imagen hero en WebP
   - Lazy loading para imágenes below-the-fold
   - Preload de la font principal

2. **CLS (Cumulative Layout Shift) < 0.1**
   - Dimensiones fijas para todas las imágenes
   - Sin contenido que se carga después del DOM
   - Reservar espacio para formularios

3. **INP (Interaction to Next Paint) < 200ms**
   - JavaScript minificado y diferido
   - Eliminar plugins innecesarios
   - Optimizar eventos del formulario

## SECCIÓN 4 — SEO Local vs Nacional

### Análisis: Rallusigence en Tizayuca, Hidalgo
**OPERACIÓN:** Nacional (todo México)
**UBICACIÓN FÍSICA:** Tizayuca, Hidalgo
**DECISIÓN:** Estrategia híbrida local + nacional

### Google My Business: CREAR CON LIMITACIONES
**PROS:**
- ✅ Autoridad local para búsquedas en "agencia IA Hidalgo"
- ✅ Reviews y credibilidad social
- ✅ Google Maps para clientes locales eventuales
- ✅ NAP (Name, Address, Phone) consistente

**CONTRAS:**
- ⚠️ Puede confundir a clientes de CDMX, GDL, MTY
- ⚠️ Limita percepción de escala nacional
- ⚠️ Algoritmo local puede priorizar competidores en otras ciudades

**CONFIGURACIÓN RECOMENDADA:**
```
Nombre: Rallusigence - Automatización IA México
Categoría Principal: Empresa de software
Categoría Secundaria: Agencia de marketing digital
Descripción: "Automatización con IA para negocios en todo México. Oficinas en Hidalgo con atención nacional."
```

### Geolocalización en Meta Tags
```html
<!-- NACIONAL, no específico de ciudad -->
```

### Estrategia de Contenido Local vs Nacional
**CONTENIDO NACIONAL (80%):**
- "Automatización IA para negocios en México"
- "Agencia IA México"
- "Bot WhatsApp empresas mexicanas"

**CONTENIDO LOCAL (20%):**
- "Agencia IA Hidalgo"
- "Automatización negocios Tizayuca"
- "Desarrollo web Pachuca"

**IMPLEMENTACIÓN:**
- Home y servicios principales: enfoque nacional
- Blog: mix 80% nacional, 20% local
- Páginas de ubicación específicas: solo si la demanda lo justifica
