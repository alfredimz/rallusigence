## FLUJO 1 — PROSPECTO POR GOOGLE ADS
**Desde clic en anuncio hasta solicitud de auditoría**

```
[Clic en Ad Google] → [Landing /auditoria-gratis]
        │
        ↓
[Ve hero + 3 beneficios] → [¿Confía en la propuesta?]
        │                              │
        │ ✅ SÍ                         │ ❌ NO
        ↓                              ↓
[Scroll al formulario]              [Abandona]
        │                              │
        ↓                              └─→ [Retargeting pixel]
[Llena formulario] → [¿Completa campos obligatorios?]
        │                              │
        │ ✅ SÍ                         │ ❌ NO
        ↓                              ↓
[Clic "Solicitar"]                 [Error validation]
        │                              │
        ↓                              └─→ [Corrige] ──┐
[Formulario enviado]                              ←────┘
        │
        ↓
[Redirige a /gracias] → [Ve confirmación] → [Clic WhatsApp] → [CONVERSIÓN ✓]
```

### **Puntos críticos:**
- **Abandono 1:** Hero no convence (solución: beneficios específicos)
- **Abandono 2:** Formulario muy largo (solución: solo 4 campos)  
- **Abandono 3:** Después de /gracias (solución: CTA WhatsApp inmediato)

### **Optimizaciones:**
- A/B test: hero con precio vs sin precio
- Formulario progresivo: nombre → negocio → contacto
- WhatsApp con mensaje pre-llenado: "Hola, solicité la auditoría gratis"

## FLUJO 2 — PROSPECTO ORGÁNICO (HOME)
**Desde llegada al sitio hasta contacto**

```
[Llega al Home] → [Ve hero] → [¿Propuesta clara?]
        │                           │
        │ ✅ SÍ                      │ ❌ NO
        ↓                           ↓
[Scroll a #problema]            [Rebote 3 seg]
        │                           │
        ↓                           └─→ [Retargeting pixel]
[Se identifica con dolores] → [¿Resuena el problema?]
        │                           │
        │ ✅ SÍ                      │ ❌ NO 
        ↓                           ↓
[Scroll a #servicios]           [Sigue explorando]
        │                           │
        ↓                           └─→ [Ve #testimonios] ──┐
[Ve precios] → [¿Precio aceptable?]                    ←──┘
        │                   │
        │ ✅ SÍ              │ ❌ MUY CARO
        ↓                   ↓
[Scroll a #como-funciona]   [Ve auditoría GRATIS]
        │                   │
        ↓                   └─→ [Solicita auditoría] → [CONVERSIÓN ✓]
[Entiende proceso] → [¿Confía en metodología?]
        │                   │
        │ ✅ SÍ              │ ❌ NO
        ↓                   ↓
[Scroll a #testimonios]    [Busca más info]
        │                   │
        ↓                   └─→ [WhatsApp] → [Pregunta directa]
[Ve casos de éxito] → [¿Prueba social suficiente?]
        │                   │
        │ ✅ SÍ              │ ❌ NO
        ↓                   ↓
[Scroll a #contacto]       [Abandona por incertidumbre]
        │
        ↓
[Elige acción] → [Formulario auditoría] → [CONVERSIÓN ✓]
                      │
                      └─→ [WhatsApp directo] → [CONVERSIÓN ✓]
                      │
                      └─→ [Agenda videollamada] → [CONVERSIÓN ✓]
```

### **Puntos críticos:**
- **Rebote inmediato:** Hero confuso (solución: H1 más claro)
- **Precio shock:** Sin contexto de valor (solución: beneficios antes de precios)
- **Falta confianza:** Sin prueba social (solución: testimonios prominentes)

### **Elementos de retención:**
- Sticky CTA "Auditoría gratis" siempre visible
- Progreso visual: scroll indicator en mobile
- Testimonios intercalados entre secciones

## FLUJO 3 — PROSPECTO POR REFERIDO (WHATSAPP)
**Desde mensaje directo hasta formalización**

```
[Mensaje WhatsApp] → [Responde bot o Alfredo]
        │
        ↓
[Saludo + calificación] → [¿Prospecto calificado?]
        │                           │
        │ ✅ SÍ                      │ ❌ NO CALIFICA
        ↓                           ↓
[Envía link sitio web]          [Despedida educada]
        │                           │
        ↓                           └─→ [Nurturing posterior]
[Visita Home desde WhatsApp]
        │
        ↓
[Ve propuesta completa] → [¿Confirma interés?]
        │                           │
        │ ✅ SÍ                      │ ❌ NO
        ↓                           ↓
[Regresa a WhatsApp]            [No responde]
        │                           │
        ↓                           └─→ [Follow up 48h]
[Agenda videollamada] → [¿Acepta reunión?]
        │                           │
        │ ✅ SÍ                      │ ❌ NO
        ↓                           ↓
[Confirma fecha/hora]           [Propone auditoría gratis]
        │                           │
        ↓                           └─→ [Acepta] → [CONVERSIÓN ✓]
[REUNIÓN AGENDADA ✓]
```

### **Mensaje bot de calificación:**
```
¡Hola! 👋 Soy el asistente de Rallusigence.

Para ayudarte mejor, dime:
1. ¿Qué tipo de negocio tienes?
2. ¿Tienes página web actualmente?
3. ¿Qué quieres automatizar?

Te conectaré con Alfredo en seguida 🚀
```

### **Puntos críticos:**
- **No califica:** Bot filtra mal (solución: mejor script de preguntas)
- **No visita web:** Desconfianza del link (solución: vista previa + dominio claro)
- **No regresa:** Se queda en el sitio (solución: CTA "Regresa a WhatsApp")

### **Scripts de seguimiento:**
- 2 horas: "¿Pudiste revisar la propuesta?"
- 24 horas: "Te dejo el link de la auditoría gratis: [URL]"
- 48 horas: "¿Hay algo específico que quieras saber?"

## MÉTRICAS DE CONVERSIÓN POR FLUJO

### **Flujo 1 (Ads):**
- Meta: 15-25% conversion rate (landing → formulario)
- Benchmark: 100 clics → 20 formularios → 5 clientes potenciales

### **Flujo 2 (Orgánico):**
- Meta: 2-5% conversion rate (visita → contacto)
- Benchmark: 100 visitas → 3 contactos → 1 cliente potencial

### **Flujo 3 (WhatsApp):**
- Meta: 40-60% conversion rate (mensaje → reunión/auditoría)
- Benchmark: 10 mensajes → 5 reuniones → 2 clientes

## RECUPERACIÓN DE ABANDONO

### **Email nurturing (si capturamos email):**

- Bot programa mensajes: 2h, 24h, 48h, 1 semana
- Escalamiento a humano si responde en cualquier momento
