## NOTAS DE IMPLEMENTACIÓN

### **Espaciado sistema 8px:**
- Secciones: 80px vertical spacing
- Elementos: 24px entre cards/bloques
- Texto: 16px entre párrafos
- Micro: 8px padding interno

### **Tipografía:**
- H1: 28px mobile, 48px desktop
- H2: 24px mobile, 36px desktop  
- Body: 16px, line-height 1.5
- Small: 14px para disclaimers

### **Colores:**
- Teal principal: #00A4A3
- Negro texto: #1a1a1a
- Gris texto: #666666
- Background: #ffffff
- Gris claro: #f8f9fa

### **Breakpoints:**
- Mobile: 320px - 767px
- Tablet: 768px - 1199px
- Desktop: 1200px+

### **CTAs:**
- Primario: background teal, texto blanco, 44px height mobile
- Secundario: border teal, texto teal, mismo height
- Sticky: fixed bottom, 56px height, sombra sutil
